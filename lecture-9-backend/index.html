Task 4 — Why do we need a backend?

JavaScript in the browser runs on the client — it has no access to databases, files, or secret credentials. A backend runs on a server, where we can securely store data, apply business logic, and expose it as an API to any frontend or mobile app. It also means one single source of truth instead of duplicating logic across every client.
